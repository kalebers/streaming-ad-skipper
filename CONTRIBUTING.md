# Contributing

Please include a focused test with behavior changes. Adapter changes must
identify the observable evidence used, explain why it cannot misclassify ordinary
content, and include a manual verification note. Do not submit credentials,
watch history, captured media, or sensitive URLs.

Run `npm run typecheck && npm test && npm run lint && npm run build` before
opening a pull request.

Submitting a pull request grants KalebeRS the contribution rights described in
the [license](./LICENSE). A pull request is the permitted way to propose help
with this project; do not copy, mirror, redistribute, publish, or reuse the
project outside the permissions granted by that license.
